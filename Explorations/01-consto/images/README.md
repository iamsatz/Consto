# Consto · Image specs

Suggested visuals for the Consto exploration page. Listed in order of priority — start at the top.

## 01 · Hero image (required)

**File:** `hero.jpg` (referenced in markdown frontmatter)
**Dimensions:** 1600×900 (16:9), retina source 3200×1800
**Treatment:** Warm, editorial. Cream/saffron palette.

**Suggested content (pick one):**

- **Option A · The store at dawn** — A render or photo of the Consto Home store-front in Beeramguda at 6am. Saffron signage, warm interior light spilling onto the footpath, a fresh-produce crate being unloaded. Atmospheric, not literal.
- **Option B · The four-format grid** — Four square illustrations side by side: Daily, Home, Hub, Route. Minimal flat style, distinct accent color per format (saffron, sage, gold, terra). Title overlay.
- **Option C · The kirana counter, present and past** — A diptych: left half a memory-painting of your father's kirana in Gadwal (warm, textured); right half a clean render of the Consto Home counter. Visual essay of the journey.

**Recommended:** Option C — most personal, hardest to fake, immediately conveys the founder thesis.

## 02 · Memory Engine diagram (high impact)

**File:** `memory-engine.svg` (or `memory-engine.png` fallback)
**Dimensions:** 1200 wide, height as needed (aim for 600-800)
**Treatment:** Clean, isometric or flat. White/cream background.

**Content:** Two inputs (Company-trained baseline + Customer behaviour signal) feeding a central engine, with four outputs flowing out (Customer suggestions, Weekly insights, AI-suggested tasks, Wisdom).

Should visually communicate the "Memory → Knowledge → Wisdom" progression.

This is the most distinctive technical concept in Consto. A clean diagram makes the architecture instantly graspable.

## Image style notes

- **Avoid stock photography** — always reads as fake on a designer portfolio
- **Cream/warm-white backgrounds** — match the portfolio palette (#F8F5F0)
- **Accent color**: saffron (#C76737 in the new minimalist palette; #E8732A in the original)
- **No clickbait visual style** — no gradients, no glow effects, no glassmorphism
- **Editorial quality** — like a long-form NYT feature, not a startup landing page

## Tools to create these

- **Diagrams** — Figma, Excalidraw, or just hand-drawn and photographed
- **Mockups** — Figma + the Consto brand tokens (palette + font already documented)
- **Renders** — Midjourney with very tight prompts, or commissioned illustration
- **Photos** — own iPhone is fine if the store exists; otherwise reference-style only
