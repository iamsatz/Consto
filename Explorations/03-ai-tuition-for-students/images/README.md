# AI Tuition for Students · Image specs

Suggested visuals for the AI Tuition exploration page.

## 01 · Hero image (required)

**File:** `hero.jpg`
**Dimensions:** 1600×900 (16:9)
**Treatment:** Warm, hopeful. Avoid stock-photo classroom shots.

**Suggested content:**

- **Option A · Phone screen + question** — A close-up of a phone showing a WhatsApp-style chat where a student is being asked *"What does the question look like to you?"* instead of given an answer. Warm cream background.
- **Option B · Two paths illustration** — Visual metaphor: one path of "answer-giving" (rushed, busy, kid looks confused) vs another of "understanding-building" (slower, kid looks curious). Illustrated style.
- **Option C · A 9th-class notebook open** — Photograph or render of a student's actual notebook with messy work-in-progress on a Math problem. Honest, unstaged. Conveys the "this is where learning actually happens" aesthetic.

**Recommended:** Option A — most direct to the product idea, easiest to read on the portfolio page.

## 02 · The conversation pattern (chat mockup)

**File:** `conversation-pattern.png`
**Dimensions:** 1200×1600 (mobile aspect)
**Treatment:** WhatsApp-style chat UI, but cleaner.

**Content:** A 6-8 message conversation showing the "patient tutor" pattern in action:

```
Student: I don't know how to solve question 3
Tutor: Show me how you read the question. What numbers do you see?
Student: It says 3/4 + 1/2
Tutor: Okay good. What did you try first?
Student: Add the top numbers, 3+1 = 4
Tutor: That's where most people start. Now the question is — can we add fractions like normal numbers? What feels off about it?
Student: ...the bottom numbers are different
Tutor: Yes! That's the whole problem. We need to make the bottoms match before we can add. Want to try?
```

This is the core product moment. Showing it visually is worth 1000 words of description.

**File:** `bilingual-switch.png`

## Image style notes

- Use warm, hopeful tones — this is about confidence, not stress
- Real-feeling content > polished stock content
- Show actual Telugu/Hindi script where relevant (don't just write "[Telugu text here]")
- Mobile-first mockups — most students will use this on phones
- Avoid "happy kid with laptop" stock photos at all costs

## Minimum viable image set

1. Hero (Option A — phone showing the chat pattern)
2. Conversation pattern mockup
3. Bilingual switch mockup

These three carry the entire product idea visually. Everything else is optional.
